Welcome to Dialosaur

The future of communication is looking a bit more prehistoric!


Dialosaur combines a custom Flutter admin portal, a cross-platform softphone, a Dart-powered middleware layer and an Asterisk PBX running on low-cost hardware to create a modern communications platform from the ground up.

Built with Flutter, Dart, Asterisk and Raspberry Pi.

Why Dialosaur?


Dialosaur started as a project to make a self-hosted phone system to learn more about SIP technology. Building a phone system from the ground up using Asterisk on a Raspberry Pi and then building a custom admin portal and softphone with Flutter.


It was also interesting to see how much of the system could be built with a single language and framework.

System Architecture

The system architecture of Dialosaur is designed to be modular and scalable.


Asterisk PBX

The Asterisk PBX serves as the core telephony engine, handling call processing and management. Handling the following;

  • SIP Trunking
  • Call Routing
  • Voicemail
  • Conference Calling
  • IVR (Interactive Voice Response)
  • Call Recording


Dart Shelf Middleware

This layer acts as a bridge between the Asterisk PBX and the Flutter applications. Instead of exposing clients directly to the PBX, Dart Shelf provides a clean API for communication between Asterisk and the Flutter applications by handling;

  • Authentication
  • REST APIs
  • User Management
  • Rate Limiting
  • Logging and Monitoring


Flutter Admin Portal

The Flutter Admin Portal provides a user-friendly interface for managing the Dialosaur system

  • Create and manage extensions
  • View system health
  • System Settings
  • Voicemail Management
  • Analytics and Reporting


Flutter Softphone

The Flutter Softphone provides a modern, feature-rich interface for making and receiving calls, with seamless integration into the Dialosaur system.

  • Make and receive calls
  • Call history
  • Contacts management
  • Voicemail integration
  • Conference calling

Available on Android, Web and Windows.

Development Journey

The development journey of Dialosaur has been an exciting and educational experience, with many challenges and learning opportunities along the way.

Phase 1: Asterisk PBX Setup

The first phase involved setting up the Asterisk PBX on a Raspberry Pi, configuring SIP trunking, and establishing basic call routing and voicemail functionality.

Phase 2: Dart Shelf Middleware

The second phase focused on developing the Dart Shelf middleware layer, which provided a clean API for communication between the Asterisk PBX and the Flutter applications.

Phase 3: Flutter Admin Portal

The third phase involved building the Flutter Admin Portal, which provided a user-friendly interface for managing the Dialosaur system.

Phase 4: Flutter Softphone

The final phase focused on developing the Flutter Softphone, which provided a modern, feature-rich interface for making and receiving calls.
